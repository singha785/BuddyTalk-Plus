* Voice Calling:
  → LiveKit (self-hosted or cloud free tier)

* Notifications:
  → Firebase Cloud Messaging (FCM)

## 🔐 STEP 1: AUTHENTICATION + USER SYSTEM

Implement Firebase Authentication:

* Phone OTP login (mandatory)
* Store user profile in Firestore:

  * name
  * role (learner / mentor)
  * english level
  * interests
  * isOnline (true/false)

---

## 🟢 STEP 2: REAL-TIME ONLINE PRESENCE

Use Firebase Realtime Database:

Features:

* When app opens → set user "online"
* When app closes → set "offline"
* Maintain:
  /presence/{userId} → online/offline

UI:

* Replace all fake "Live Now" with real-time data
* Show only currently online users

---

## 🎧 STEP 3: VOICE CALLING (CORE FEATURE)

Integrate LiveKit SDK:

Features:

* 1-to-1 voice call
* Auto join room when matched
* Call timer (15 min free)
* Mute/unmute
* Auto disconnect

Flow:

1. Match found
2. Generate room
3. दोनों users join same room
4. Voice call starts

---

## 🤝 STEP 4: MATCHING SYSTEM (SIMPLE + EFFECTIVE)

Create queue-based matching:

Firestore collection:

* /waitingQueue

Logic:

* User clicks "Start Talking"
* Add user to queue
* Match with next available user

Filters:

* Same English level (optional)
* Mentor priority (if available)

---

## 👨‍🏫 STEP 5: MENTOR SYSTEM (BASIC VERSION)

Create mentor onboarding:

Form fields:

* Name
* Experience
* Language level
* ID upload (store in Firebase Storage)

Flow:

* Mentor applies
* Status = pending
* Admin manually approves (via Firestore flag)

After approval:

* Mentor becomes available for matching

Send notifications:
